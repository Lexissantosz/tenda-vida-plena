# Tenda de Umbanda Vida Plena

Primeira versão do sistema responsivo da Tenda de Umbanda Vida Plena.

## Objetivo

Criar uma plataforma mobile-first para apoiar a rotina da casa e dos irmãos de santo, reunindo:

- agenda e próximas giras;
- estudos e materiais;
- pontos e músicas;
- chamados e necessidades do terreiro;
- favoritos e anotações;
- perfis com permissões diferentes;
- futuras áreas administrativas para responsáveis da casa.

## Stack atual

- React
- TypeScript
- Vite
- CSS responsivo
- Lucide React

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Status

A versão atual é uma base visual e interativa da Home. Os dados são simulados e servem para validar layout, responsividade e experiência antes da integração com backend e banco de dados.

Já existem nesta primeira tela:

- navegação responsiva para desktop e celular;
- próxima gira em destaque;
- chamados do terreiro com ação “Vou levar”;
- área de estudos com progresso;
- pontos recentes;
- busca visual;
- atalhos;
- identidade visual inspirada nas referências enviadas.

## Direção visual

A interface segue a identidade de referência da Tenda de Umbanda Vida Plena, usando creme, bege, dourado, carvão, taupe e verde oliva, títulos em estilo editorial e elementos inspirados na natureza.

> Símbolos, conteúdos religiosos, datas e funções administrativas deverão ser validados com os responsáveis da casa antes de serem tratados como definitivos.
